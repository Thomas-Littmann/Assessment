CanTypeA * CanAdapterA::getHardware ( )

Methode um Bypass von Applikation auf Hardware CanTypeA direkt zu ermöglichen.

In diesem Fall ist es bspw. für die Methode setBaudrate(eBaudrate baudrate), welche eine Spezialfunktion von CanTypeA ist. Per Downcast kann die Applikation auf diese Spezialfunktion an dem einheitlichem Interface vorbei zugreifen.
