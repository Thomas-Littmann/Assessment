CanTypeE * CanAdapterE::getHardware ( )
inline

Methode um Bypass von Applikation auf Hardware CanTypeE direkt zu ermöglichen.

In diesem Fall ist es bspw. für die Methode sendMessageStruct(messageStruct* message), welche eine Spezialfunktion von CanTypeE ist. Per Downcast kann die Applikation auf diese Spezialfunktion an dem einheitlichem Interface vorbei zugreifen.

Zyklische Verarbeitung. Ermöglicht Polling für den Empfang von Nachrichten.

Zyklische Abfrage von Nachrichten bei der Hardware. Bei Erhalt von Nachrichten werden diese an die registrierte Callback-Funktion weitergeleitet. Hinweis: Die aktuelle Hardware-API bietet keinen öffentlichen Zugriff auf handleMessage()) oder Empfangsregister

Rückmeldung von Fehlern über Callback. Hier wird geprüft, ob die Hardware initialisiert ist und ob die Nachricht nicht zu lang ist.
